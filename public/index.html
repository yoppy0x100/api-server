Available Endpoints

TikTok API

GET /api/tokkit

Fetch TikTok user information, music, or video data.

Query Parameters:
  • username - Get TikTok user information
  • music - Get music information
  • video - Get video information

Example: /api/tokkit?username=example

Gacoan Finder API

GET /api/gacoanfinder

Retrieve Gacoan location and information data.

Example: /api/gacoanfinder
